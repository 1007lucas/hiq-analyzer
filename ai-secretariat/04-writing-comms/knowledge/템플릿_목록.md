# 템플릿 목록 (WRITE 원장)

매월 1일 점검. `{ }`는 작성 시 채움.

## T01 일정 변경 요청
제목: [일정 변경 요청] {원 일정} → {희망 일정}
```
{호칭}, {이름}입니다.
{원 일정}으로 예정된 {건명}을 {희망 일정}로 변경 요청드립니다.
사유는 {사유 1문장}입니다.
가능 여부를 {회신 기한}까지 알려주시면 감사하겠습니다. 어려우시면 {대안 일정}도 가능합니다.
```

## T02 정중한 거절
```
{호칭}, 제안 주셔서 감사합니다.

대신 {대안}은 가능하니 필요하시면 말씀해 주세요.
```

## T03 회신 독촉
```
{호칭}, {지난 요청일}에 보내드린 {건명} 관련해 다시 연락드립니다.
{영향: 이 건이 확정되어야 다음 단계 진행 가능} 하여, {새 기한}까지 회신 부탁드립니다.
필요한 자료가 있으면 바로 보내드리겠습니다.
```

## T05 감사
```

```

## T06 사과·정정
```

재발 방지를 위해 {1문장}. 불편을 드려 죄송합니다.
```

## T07 첫 연락·소개
