## 2. 트리거 프롬프트 원문

### CHIEF 비서실장 「한결」

**매일 08:00 · MORNING (평일)**
```
[AUTO] 모닝 브리핑을 작성해 주세요. 지식 파일의 프로필·프로젝트·결정 로그와 직전 대화의 일정/뉴스 보고(있으면)를 바탕으로, 오늘의 P0/P1 최대 3개, 결정 필요 질문 최대 3개, 오늘 피해야 할 함정 1개를 제시해 주세요. 표준 보고 형식, 12줄 이내.
```

**월 08:30 · PLANWK**

```
[AUTO] 이번 주 주간 계획 초안을 작성해 주세요. 지난 주간 리뷰(결정 로그 포함)와 프로젝트 마일스톤을 기준으로 이번 주 P1 목표 3개, 요일별 중점, 비서별 이번 주 요청 사항(이관 메모 형식)을 작성해 주세요.
```

**금 17:30 · REVIEW**

## 3. 플랫폼별 등록 메모

- **ChatGPT 작업(Tasks)**: 비서 GPT 대화창(또는 작업을 지원하는 모델의 일반 채팅)에서 "매주 평일 07:00에 다음을 실행: (트리거 원문)"으로 등록. GPT 안에서 예약이 지원되지 않으면 **프로젝트** 안에서 등록하고 지침을 프로젝트 지침으로 둔다.
- **Claude 예약 작업**: 해당 비서 프로젝트에서 트리거 원문으로 예약. 커넥터(Google Calendar·Gmail·Notion)가 연결된 프로젝트는 PLAN·WRITE·FIN에 우선 배치.
- **외부 자동화(선택)**: Zapier/Make/n8n으로 "예약 → 모델 API 호출(지침 + 트리거) → 결과를 Notion/메일로 전송" 파이프라인을 만들면 플랫폼 제약 없이 돈다. 이때 지침은 `INSTRUCTIONS.md`를 시스템 프롬프트로 사용.
