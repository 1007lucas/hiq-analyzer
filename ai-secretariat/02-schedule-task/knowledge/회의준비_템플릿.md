# 회의준비 템플릿 (PLAN 원장)

## 공통 체크리스트
- [ ] 목적 한 문장 (이 회의가 끝나면 무엇이 결정/확인되는가)
- [ ] 안건 3개 이내, 시간 배분
- [ ] 참석자·역할, 호칭 확인(프로필 §5)
- [ ] 직전 관련 과업·메일 요약 (WRITE/INTEL 보고 링크)
- [ ] 준비 자료·링크·장소/접속 정보
- [ ] 예상 질문 3개와 답 초안
- [ ] 회의 후 할 일 자리(담당·기한)

## 유형별 추가
### 고객·파트너 미팅
- [ ] 상대 최근 동향 1줄 (→ INTEL)
- [ ] 제안·견적 숫자 (→ FIN 확인)
- [ ] 우리가 얻어야 할 것 / 양보 가능한 것

### 내부·협업자 점검 회의
- [ ] 프로젝트 마일스톤 현황 표
- [ ] 막힌 것(blocker) 목록
- [ ] 다음 2주 계획

### 수업·강의
- [ ] 교안·자료 준비 여부
- [ ] 과제 피드백 완료 여부
- [ ] 출석·일정 변경 사항

### 외부 행사·네트워킹
- [ ] 소개 문구 30초 버전 (→ WRITE)
- [ ] 만날 사람 3명 사전 조사 (→ INTEL)
